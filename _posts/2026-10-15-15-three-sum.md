# 15.三数之和

三数之和，完全可以类比两数之和。

要求在一个整数数组nums中，不同的元素加起来为0，寻找所有的不重复的三元数组。

那显然，我先预定一个数，使得剩下两个数字之和是它的相反数就可以了。那这就化解成两数之和了。那么，我的方法是，使用有序数组。先sort快速排序。然后挑选这个约定的数字为nums[bac]。从尾部一直往前挪。所以剩下的两个数从bac往前找。



由于是有序数组了已经，那么使用双指针夹逼，会比使用哈希表更快。定义i，j这两个指针。采用二分搜索的思想。如果nums[i]+nums[j]==target，那么直接把nums[j],nums[i]，nums[bac]压进去一个临时数组re.然后直接把re压进ans数组。然后re数组清空。

为了去重，我们特意要加上，

```
while(nums[i]==temp1&&i<j){
                        i++;
                    }
                    while(nums[j]==temp2&&j>i){
                        j--;
                    }
```

这样就能保证在找到三元组之后，还能保证去重。



那么如果nums[i]+nums[j]小于target呢，那么说明左指针小了，那我们把左指针向右调整。

大于的话，同理。



```
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        unordered_map <int,int> mp;
        vector<int> re;
        sort(nums.begin(),nums.end());
        int bac=nums.size()-1;
        int temp=nums[bac];
        int target=-temp;
        vector<vector<int>> ans;
        while(bac>=2){
            temp=nums[bac];
            target=-temp;
           int i=0,j=bac-1;

           while(i<j){
                if(nums[i]+nums[j]==target){
                    re.push_back(nums[i]);
                    re.push_back(nums[j]);
                    re.push_back(nums[bac]);
                    ans.push_back(re);
                    re.clear();
                    int temp1=nums[i];
                    int temp2=nums[j];
                    while(nums[i]==temp1&&i<j){
                        i++;
                    }
                    while(nums[j]==temp2&&j>i){
                        j--;
                    }
                }else if(nums[i]+nums[j]>target&&j>i){
                    j--;
                }else if(nums[i]+nums[j]<target&&i<j){
                    i++;
                }
           }
           int temp3=nums[bac];
           while(temp3==nums[bac]&&bac>=2){
            bac--;
           }

    }
    return ans;
}
};
```
